# Remoter FS logo

Created with the built-in ImageGen tool. The generated PNG was copied into the
project unchanged as `assets/remoter-fs-icon.png` and registered through the
extension manifest's `icon` field.

## Final prompt

Use case: logo-brand. Asset type: production extension icon for Remoter FS, an FTP/FTPS remote file editor for VS Code and Cursor. Create ONE finished square app icon, not a presentation or a sheet of variants. A distinctive, minimal geometric folder symbol integrated with two opposing transfer arrows, communicating remote folders and direct file transfer. Bold simple silhouette and generous negative space so it stays recognizable at 32 and 48 pixels. Crisp flat vector-like shapes, a restrained modern software-brand treatment, clear contrast, centered composition. An opaque rounded-square tile with genuinely transparent outer corners; the mark should fill most of the tile with comfortable padding. No lettering, no words, no initials, no watermark, no mockup, no surrounding scene, no fine lines, no tiny server details. Square 1024 by 1024 PNG. This is a brand-new logo; do not reproduce any existing VS Code, Cursor, or Remote FS logo.

Transparent background: enabled. The actual generated image is 1254 × 1254 pixels.
