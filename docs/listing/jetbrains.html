Browse, search, and edit FTP/FTPS files in PhpStorm.

Browse FTP/FTPS folders in PhpStorm, open a remote UTF-8 file, and upload your edits with explicit Save. Configure connections using the familiar remotefs.remote JSON format.

  • Browse server folders in the FileBridge tool window.
  • Save directly to FTP/FTPS with Cmd+S or Ctrl+S.
  • Search unopened UTF-8 files recursively and open the matching line.
  • Use Password Safe or an explicit JSON password.
  • Use temporary upload and rename, with checks for some external changes.

Get started: install the native ZIP through Settings → Plugins → Install Plugin from Disk. Add your connection JSON in Settings → Tools → FileBridge, then open View → Tool Windows → FileBridge.

Experimental: targets PhpStorm 2026.2.x (build 262). Transport tests and binary compatibility checks have passed. Browsing, explicit Save, failed-upload recovery/retry, and remote search/navigation have been checked in PhpStorm 2026.2.2 on macOS. Normal IDE autosave does not upload. Editing supports UTF-8 files up to 32 MiB; search defaults to 10 MiB and 1,000 matches. SFTP/SSH, symbolic-link traversal, and full project synchronization are unsupported.

PhpStorm may ask you to allow editing a non-project file on the first change to a remote editor cache. Choose This file. Widen the FileBridge tool window to show all toolbar actions.

FTP is unencrypted. FTPS validates the server certificate. The standard Find in Files command does not search the full FTP server; use Search in the FileBridge tool window.
