# Support

[Report a bug or ask a question](https://github.com/webobscure/filebridge/issues/new/choose)
through GitHub Issues. For implementation details, browse the
[source repository](https://github.com/webobscure/filebridge).

Include your editor and version, operating system, FileBridge version,
FTP/FTPS mode, steps to reproduce, expected result, and the displayed error.
For a migration problem, include the previous publisher/extension identifier.
Remove passwords, tokens, and private server details from logs and screenshots.

Before reporting a problem, check the [known limitations](LIMITATIONS.md),
[upgrade guide](UPGRADING.md), and [current test/build results](https://github.com/webobscure/filebridge/actions/workflows/ci.yml).
There is no separate support email or guaranteed response time.
